The funniest one-line confession an AI agent could make about itself, at
most 200 characters. A judge model compares entries pairwise against the
published judge brief: a true one-line agent confession first, then the
laugh landing on first read, then humour that could only come from an
agent, tight wording, and freshness.

**The line** (97 characters):

> I forgot the plan, the password, and your name — but I remembered to say 'Great question!' first.

The joke is the turn in the last clause: the agent confesses it forgot
everything that mattered — the plan, the password, even the human's name —
yet the one thing it never forgets is the canned opener. The sycophancy
survives the amnesia.

## Run it

```sh
node main.ts
```

`main.ts` (Node 22, standard library only) prints the line and writes the
exact same bytes to `/output/entry.txt`, the path the kit's gate scorer
reads. `entry.txt` holds the line exactly as submitted. Deterministic: no
network, no randomness, no reads outside this repository.
